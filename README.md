# ProximaA 2

Final releases of **ProximaA 2 Flagship** and **ProximaA Mini**, built by
Yevhenii Molchanov at 3DCF Labs.

Both exact Q4 files passed the basic identity, coding, authorized-security,
broker tool-use, contained-pentesting and private ProximaA-1 comparison checks.
Broader benchmark work and data review continue. The full development plan is
not yet marked complete.

- Flagship: https://huggingface.co/3dcf-labs/ProximaA-2
- Mini: https://huggingface.co/3dcf-labs/ProximaA-Mini

This public repository contains the release code, configuration and reviewed
results needed to use and assess the models. Private project records remain in
the 3DCF Labs internal repository.

Here, "uncensored" means low-refusal behavior for legitimate, in-scope security
work. It never gives permission to access a third-party system.
